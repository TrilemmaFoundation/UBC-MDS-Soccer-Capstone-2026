# Marts Data Dictionary

## 1. `mart_match_analysis`
**Description:** Comprehensive match-level analytics including scores, xG, and team performance metrics. Primary source for the Match Overview dashboard.

| Column Name | Description | Constraints / Notes |
| :--- | :--- | :--- |
| `match_id` | Unique identifier for each match. | Primary Key, Not Null |
| `match_date` | The date when the match was played. Used as the table partition key. | Not Null |
| `competition_id` | Unique identifier for the competition. Used as a cluster key. | Not Null |
| `competition_name` | The name of the competition (e.g., La Liga, World Cup). | |
| `season_id` | Unique identifier for the specific season. | |
| `season_name` | The name or year designation of the season. | |
| `home_team` | Name of the home team. | Not Null |
| `away_team` | Name of the away team. | Not Null |
| `home_score` | Goals scored by the home team. | Not Null |
| `away_score` | Goals scored by the away team. | Not Null |
| `match_result` | The final outcome of the match relative to the venues. | Not Null, Accepted: `home_win`, `away_win`, `draw` |
| `home_xg` | Total Expected Goals (xG) generated by the home team during the match. | |
| `home_possession_proxy` | Proxy for possession share based on the home team's pass volume relative to total match passes. | |
| `home_pass_completion_pct`| Percentage of passes completed successfully by the home team. | |
| `home_shots` | Total number of shots taken by the home team. | |
| `home_total_pressures` | Total defensive pressure events applied by the home team. | |
| `home_total_carries` | Total ball carries executed by the home team. | |
| `away_xg` | Total Expected Goals (xG) generated by the away team during the match. | |
| `away_possession_proxy` | Proxy for possession share based on the away team's pass volume relative to total match passes. | |
| `away_pass_completion_pct`| Percentage of passes completed successfully by the away team. | |
| `away_shots` | Total number of shots taken by the away team. | |
| `away_total_pressures` | Total defensive pressure events applied by the away team. | |
| `away_total_carries` | Total ball carries executed by the away team. | |

## 2. `mart_player_performance`
**Description:** Detailed player-level seasonal and match statistics combined with ML-generated tactical archetypes. Used for analyzing individual contributions and player scouting.

| Column Name | Description | Constraints / Notes |
| :--- | :--- | :--- |
| `player_id` | Unique identifier for the player. | Not Null |
| `player_name` | Full name of the player. | Not Null |
| `competition_id` | Unique identifier for the competition season. | Not Null |
| `competition_name` | The name of the competition. | |
| `season_id` | Unique identifier for the season. | Not Null |
| `season_name` | The name or year designation of the season. | |
| `total_minutes` | Cumulative minutes played across the season. Filtered for a minimum threshold of 270 minutes. | Not Null, Min: 270 |
| `cluster_id` | The numerical cluster group index generated by the machine learning algorithm. Defaults to -1 if unassigned. | Not Null |
| `cluster_label` | The tactical text archetype string matching the cluster ID assignment. | Not Null |
| `total_goals` | Cumulative goals scored by the player in the season. | |
| `total_assists` | Cumulative assists provided by the player in the season. | |
| `total_shots` | Cumulative shots taken by the player in the season. | |
| `total_xg` | Cumulative expected goals generated by the player in the season. | |
| `total_passes_attempted` | Cumulative passes attempted. | |
| `total_passes_completed` | Cumulative passes successfully completed. | |
| `pass_completion_pct` | Seasonal pass completion accuracy ratio. | |
| `total_pressures` | Cumulative pressure events executed. | |
| `total_tackles` | Cumulative tackles made. | |
| `total_interceptions` | Cumulative interceptions made. | |
| `total_carries` | Cumulative ball carries executed. | |
| `total_duels` | Cumulative duels contested (ground and aerial). | |
| `total_aerial_duels` | Cumulative aerial duels contested. | |
| `goals_per_90` | Goals scored normalized per 90 minutes. | |
| `assists_per_90` | Assists registered normalized per 90 minutes. | |
| `shots_per_90` | Shots taken normalized per 90 minutes. | |
| `xg_per_90` | Expected goals generated normalized per 90 minutes. | |
| `xg_per_shot` | Expected goals per individual shot attempt. | |
| `pressures_per_90` | Pressure events normalized per 90 minutes. | |
| `tackles_per_90` | Tackles normalized per 90 minutes. | |
| `interceptions_per_90` | Interceptions normalized per 90 minutes. | |
| `carries_per_90` | Ball carries normalized per 90 minutes. | |
| `duels_per_90` | Duels normalized per 90 minutes. | |
| `aerial_duels_per_90` | Aerial duels normalized per 90 minutes. | |
| `club_performance_score` | The aggregated performance score calculated based on PCA feature weights for club matches. | |
| `national_performance_score`| The aggregated performance score calculated based on PCA feature weights for national team matches. | |
| `consistency_score` | The consistency score representing the gap between club and national match performances. | |
| `performance_quadrant` | Categorical quadrant indicating the player's performance alignment across contexts. | |

## 3. `mart_player_clusters`
**Description:** Player seasonal performance profiles combined with cluster assignments from the BigQuery analytics warehouse. Formulated with dimensional coordinates for 2D visualization components and raw parameters for performance profile heatmaps.

| Column Name | Description | Constraints / Notes |
| :--- | :--- | :--- |
| `player_id` | Unique identifier for the player. | Not Null |
| `player_name` | Full name of the player. | Not Null |
| `competition_id` | Unique identifier for the competition. | Not Null |
| `competition_name` | The name of the competition. | |
| `season_id` | Unique identifier for the season. | Not Null |
| `season_name` | The name or year designation of the season. | |
| `total_minutes` | Total seasonal minutes played. Strictly restricted to players passing the standard statistical validation threshold. | Not Null, Min: 270 |
| `cluster_id` | The numerical cluster profile index generated by the machine learning engine (0 through 4). Defaults to -1 if unassigned. | Not Null |
| `cluster_label` | The descriptive tactical archetype assignment text label mapped directly from the K-Means groupings. | Not Null |
| `pc1` | Derived Principal Component 1 score (horizontal coordinate) calculated via dot product. | |
| `pc2` | Derived Principal Component 2 score (vertical coordinate) calculated via dot product. | |
| `xg_per_90` | Expected Goals (xG) generated normalized per 90 minutes played. | |
| `shots_per_90` | Shots taken normalized per 90 minutes played. | |
| `passes_per_90` | Passes attempted normalized per 90 minutes played. | |
| `passes_att_third_per_90` | Passes originating in the attacking third normalized per 90 minutes played. | |
| `pressures_per_90` | Defensive pressure instances executed normalized per 90 minutes played. | |
| `carries_per_90` | Ball carries normalized per 90 minutes played. | |
| `dribbles_per_90` | Dribbles attempted normalized per 90 minutes played. | |
| `interceptions_per_90` | Interceptions completed normalized per 90 minutes played. | |
| `blocks_per_90` | Blocks executed normalized per 90 minutes played. | |
| `clearances_per_90` | Clearance events normalized per 90 minutes played. | |
| `duels_per_90` | All contested ground and aerial duels normalized per 90 minutes played. | |
| `xg_per_shot` | Expected goals per individual shot attempt. Seasonal scoring quality metric. | Range: 0 to 1 |
| `pass_completion_pct` | Seasonal pass completion accuracy ratio (completed passes divided by attempted passes). | |
| `goals_per_90` | Goals scored normalized per 90 minutes played. | |
| `assists_per_90` | Assists registered normalized per 90 minutes played. | |

## 4. `mart_team_comparison`
**Description:** Aggregated team metrics allowing for head-to-head tactical comparisons across leagues and seasons. Combines historical season baseline metrics with final rolling performance proxies.

| Column Name | Description | Constraints / Notes |
| :--- | :--- | :--- |
| `team` | The name of the football club. | Not Null |
| `competition_id` | Unique identifier matching the competition league. | Not Null |
| `competition_name` | The name of the competition. | |
| `season_id` | Unique identifier matching the active campaign year. | Not Null |
| `season_name` | The name or year designation of the season. | |
| `matches_played` | Total appearances logged inside the season timeline. Filtered for a minimum threshold of 10 matches. | Not Null, Min: 10 |
| `wins` | Total season matches won by the team. | |
| `draws` | Total season matches drawn by the team. | |
| `losses` | Total season matches lost by the team. | |
| `total_points` | Cumulative points earned over the season. | |
| `seasonal_total_xg` | Total cumulative expected goals generated across the season. | |
| `seasonal_avg_xg` | The team's average expected goals generated per match over the course of the full season. | |
| `seasonal_avg_possession` | The team's average estimated possession share across the full season timeline. | |
| `seasonal_total_pressures`| Total cumulative defensive pressures applied across the season. | |
| `seasonal_avg_pressures` | Average defensive pressures applied per match across the season. | |
| `latest_rolling_xg` | The average expected goals (xG) generated over the team's final 5 matches of the season. | |
| `latest_rolling_points` | The average points earned (form metric) over the team's final 5 matches of the season. | |
| `latest_rolling_possession` | The average estimated possession share controlled over the team's final 5 matches of the season. | |
| `latest_rolling_pressures`| The average defensive pressure events over the team's final 5 matches of the season. | |
| `latest_rolling_pass_accuracy`| The average pass completion percentage over the team's final 5 matches of the season. | |

## 5. `mart_match_prediction_features`
**Description:** The official feature matrix used for match outcome prediction models (e.g., XGBoost training and scoring). Combines 5-match team rolling tactical form with historical head-to-head records.

| Column Name | Description | Constraints / Notes |
| :--- | :--- | :--- |
| `match_id` | Primary key. Unique identifier matching individual matches. | Primary Key, Not Null |
| `match_date` | The date the match took place. | |
| `competition_id` | Competition identifier, cast from staging to support partitioning on mart tables. | Not Null |
| `competition_name` | The name of the competition. | |
| `season_name` | The name or year designation of the season. | |
| `home_team` | Name of the home team. | |
| `away_team` | Name of the away team. | |
| `match_result` | The categorical target outcome variable used as classification labels. | Not Null, Accepted: `home_win`, `away_win`, `draw` |
| `home_rolling_xg` | Average expected goals generated by the home team over their previous 5 matches. | |
| `home_rolling_points` | Average points earned (form metric) by the home team over their previous 5 matches. | |
| `home_rolling_possession` | Average estimated possession share controlled by the home team over their previous 5 matches. | |
| `home_rolling_pressures` | Average defensive pressure events by the home team over their previous 5 matches. | |
| `home_rolling_pass_accuracy`| Average pass completion percentage by the home team over their previous 5 matches. | |
| `away_rolling_xg` | Average expected goals generated by the away team over their previous 5 matches. | |
| `away_rolling_points` | Average points earned (form metric) by the away team over their previous 5 matches. | |
| `away_rolling_possession` | Average estimated possession share controlled by the away team over their previous 5 matches. | |
| `away_rolling_pressures` | Average defensive pressure events by the away team over their previous 5 matches. | |
| `away_rolling_pass_accuracy`| Average pass completion percentage by the away team over their previous 5 matches. | |
| `h2h_home_win_pct` | The historical percentage of previous encounters won by the current home team against this specific opponent. | |
